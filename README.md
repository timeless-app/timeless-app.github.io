# Timeless — website

Live at **https://timeless-app.github.io**

- `config.js` — links, prices and the Black Friday deal (the only file to edit for those)
- `downloads/Timeless-Setup.exe` — the Windows installer people download
- `version.json` — the latest version number; Timeless checks it for updates

To publish a new version: replace `downloads/Timeless-Setup.exe` and change the number in `version.json`.
